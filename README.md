# DEXP F49B8000K: помощник для старого Android-телевизора

Второй телевизор после [LG-Webos](https://github.com/D3vil787/LG-Webos). DEXP F49B8000K — это Konka на чипе MStar 6369, Android 4.2.1, 2015 год.

## Что получилось

Сначала здесь был свой главный экран, как на LG. От него отказались: штатный лаунчер Konka при запуске сам поднимает TV-сервис MStar (`startMsrv`), без которого у HDMI нет звука, и повторить это обычное приложение не может — у штатного системные права. Смотреть всё равно удобнее через приставку (Mi Box 4) по HDMI.

Поэтому приложение `launcher/` теперь — **«Помощник ТВ»**:

- **Автозапуск HDMI.** После включения телевизора ждёт штатный экран и сам открывает HDMI на весь экран, без нажатия OK. Работает при загрузке и при выходе из режима ожидания.
- **Плитка HDMI** для ручного переключения. Долгое нажатие OK меняет порт (HDMI 1–4).
- **Диагностика**: состояние ADB, автозапуска, скрытые экраны настроек и заводского меню.
- **Удаление приложений** через стандартный диалог Android (менеджер Konka при прямом запуске падает).
- **Экспорт APK на флешку** — системные приложения для разбора на ПК.

## Как переключается HDMI

Найдено разбором штатных `com.konka.avenger` и `com.konka.tvsettings`:

- TV-приложение переключает источник целиком (видео и звук) по интенту, которым пользуется кнопка Source:
  `action = com.konka.SwitchSource`, компонент `com.konka.tvsettings/.RootActivity`,
  extra `SwitchSourceByTVHotKey` = номер `EnumInputSource` (HDMI1 = 23, HDMI2 = 24, HDMI3 = 25, HDMI4 = 26).
- Возврат к Android-источнику — `TvManager.setInputSource(E_INPUT_SOURCE_STORAGE, false, false, false)`; штатный лаунчер делает это сам.

## Что не получилось на Android 4.2

- **ADB и root.** ADB в прошивке выключен, переключателя нет ни в меню, ни в заводском меню (`com.konka.factory`), сетевых сервисных портов нет. Остаётся только UART на плате.
- **Lampa.** Работает через Crosswalk, который берёт корневые сертификаты Android 4.2 (2012 год) и не знает ISRG Root X1 (Let's Encrypt): «Request was denied for security». Добавить сертификат нельзя — нет стандартных настроек Android для хранилища учётных данных.
- **Кинопоиск** требует Android 7+.
- **Предустановленный хлам** (Twitter, почта и т. п.) вшит в прошивку, удаляется только с root.

## Сборка

GitHub Actions собирает `dexp-home.apk` при каждом изменении в `launcher/` и кладёт его в ветку [`apk`](../../tree/apk). Подпись постоянным ключом из секретов `DEXP_KEYSTORE_B64` / `DEXP_KEYSTORE_PASSWORD`, иначе новая версия не встанет поверх старой. Android 4.2 понимает только подпись v1, она включена.

Установка на телевизор: APK на флешку → «Менеджер файлов».
