# DEXP F49B8000K: свой главный экран и чистка

Второй телевизор после [LG-Webos](https://github.com/D3vil787/LG-Webos). Здесь Android 4.2.1, поэтому главный экран сделан как обычный лаунчер Android: кнопка Home ведёт на него штатно.

Работа в процессе. Сейчас в репозитории только лаунчер.

- `launcher/` — проект Android (Java, без библиотек, minSdk 17).
- Сборка идёт в GitHub Actions при каждом изменении в `launcher/`. Готовый `dexp-home.apk` лежит в ветке [`apk`](../../tree/apk).
